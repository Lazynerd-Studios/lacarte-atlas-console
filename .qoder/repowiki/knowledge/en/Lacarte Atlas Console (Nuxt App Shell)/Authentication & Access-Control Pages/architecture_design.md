Three sibling Nuxt `<script setup lang="ts">` pages under `app/pages/`, each self-contained with inline template styles (no shared layout). `login.vue` and `forgot-password.vue` opt out of the app shell via `definePageMeta({ layout: false })` and render a full-viewport card over decorative gradient blobs; `unauthorized.vue` opts into the existing dashboard layout. State is local (`ref`/`reactive`) — there is no shared page-level store. Side effects go through composables from the app root: `useApi()` for HTTP calls, `useAuthStore().setAuth()` to persist tokens on login, `useAppToast()` for success feedback, and `useRouter()` for navigation. The login page bridges the API response (`data.user`, `data.token`) into the global auth store before redirecting to `/`; the forgot-password page posts to `/auth/forgot-password` and switches between form and success states via a `submitted` flag. All three pages depend only on the Nuxt runtime (`useRouter`, `definePageMeta`) and the app's top-level composables/stores — they do not import each other or any internal component library beyond the shared `UIcon` icon renderer.
