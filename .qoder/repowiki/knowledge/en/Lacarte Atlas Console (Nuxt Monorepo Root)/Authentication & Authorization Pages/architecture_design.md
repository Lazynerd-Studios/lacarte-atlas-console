Three sibling Nuxt `<script setup lang="ts">` pages under `app/pages/`, each a self-contained component with inline styles (no shared CSS). `login.vue` and `forgot-password.vue` opt out of the app shell via `definePageMeta({ layout: false })` and render centered card layouts with decorative gradient blobs; `unauthorized.vue` stays inside the dashboard shell (`layout: 'dashboard'`) and is intended to be reached from route guards. State and side effects live locally in `ref`/`reactive`; cross-page auth state is persisted through the global `useAuthStore.setAuth(user, token)` store. API calls go through the composables `useApi()` and `useAppToast()`. Navigation uses the Nuxt router (`router.push('/')`, `router.back()`) rather than programmatic middleware redirects.
