The root `nuxt.config.ts` is the single orchestrator: it registers shared modules (`@nuxt/ui`, `@pinia/nuxt`, `@pinia-plugin-persistedstate/nuxt`), global CSS, and runtime config (`NUXT_PUBLIC_API_BASE`, `NUXT_PUBLIC_TOMTOM_API_KEY`). File-system routing under `app/pages/` exposes the unauthenticated entry flow (`/login`, `/forgot-password`) while other directories under `app/` provide authenticated screens. Cross-cutting concerns are centralized here — route-level SSR is disabled for sensitive/public endpoints via `routeRules`, and the `~/` alias to `./app` is mirrored in both Nuxt and Vitest so tests import page components directly against happy-dom.
