The root is one Nuxt 4 app (`nuxt.config.ts`) that bootstraps every child feature via the file-system router: `app/pages/` hosts the unauthenticated entry flow (auth_pages), while other top-level directories under `app/` provide authenticated screens. Cross-cutting concerns are centralized here — global CSS (`assets/css/main.css`), Nuxt modules (`@nuxt/ui`, `@pinia/nuxt`, `@pinia-plugin-persistedstate/nuxt`), and runtime config (`NUXT_PUBLIC_API_BASE`, `NUXT_PUBLIC_TOMTOM_API_KEY`). Route-level SSR is disabled for sensitive/public endpoints (`/login`, `/forgot-password`, `/pay/**`, `/tracking/**`) via `routeRules`. The same `~`/`@` alias to `./app` is mirrored in both Nuxt and Vitest (`vitest.config.ts`) so tests can import page components directly against the happy-dom environment.
